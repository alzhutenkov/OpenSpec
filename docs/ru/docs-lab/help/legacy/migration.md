### Резервное копирование пользовательского содержимого перед очисткой

файлы, перечисленные в разделе **Файлы для удаления**, полностью удаляются. Прежде чем принять очистку, создайте резервную копию любого пользовательского содержимого.

- **`openspec/AGENTS.md`**: обнаруживается только по существованию; очистка не проверяет его содержимое.
- **Корневой уровень `AGENTS.md`, `CLAUDE.md` и других файлов конфигурации**: очистка удаляет блоки маркеров OpenSpec и сохраняет содержимое вне этих блоков.
- **Устаревшие каталоги команд**: при очистке сохраняются файлы, которые не распознаются как сгенерированные команды.
