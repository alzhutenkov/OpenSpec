# Карта сообщений: вопросы, на которые должны ответить документы, и где

Индекс [README](README.md) запускает страницу в задание. Этот файл работает по-другому: один плоский
список вопросов, на которые нам нужны документы, на которые нужно ответить, каждый
из которых указывает на группу и страницу, владеющие ответом. Статус показывает, существует ли
этот ответ еще: **Отвечено** (текст страницы-владельца получен), **Скелет** (владелец назначен, на странице
представлены только заголовки), **Пробел** (нет владельца), **Отсутствует** (ответ получен за пределами этих документов
по решению). Переверните строку на «Ответил», когда появится текст на ее странице.
Строки следуют порядку боковой панели главной страницы; Пробелы располагаются там, где должен был
находиться предполагаемый дом, а ряды за пределами участка идут последними. Держите строки
грубыми (вопрос на странице, а не предложение на разделе), чтобы обслуживание было дешевым.
