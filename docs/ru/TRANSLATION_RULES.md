# Правила перевода документации

Храните русский комплект в `docs/ru/`. Английские оригиналы остаются на прежних путях. Область перевода и проверенные версии перечислены в [реестре](translation-manifest.json).

## Выберите страницу

- Актуальные материалы: `docs-lab/` → `docs/ru/docs-lab/`.
- Прежние руководства: `docs/` → `docs/ru/docs/`. На каждой странице сохраняется предупреждение об устаревании.
- Корневые документы: `docs/ru/project/`.
- README подсистем: исходный путь внутри `docs/ru/`.

Машинные инструкции, шаблоны генерации и исходный код не переводятся. Причины исключений записаны в `exclusions` реестра. Новая страница в согласованных областях появится в отчёте как `uncovered`.

## Сохраните весь смысл

Переводите все разделы, условия, ограничения, предупреждения, описания параметров и комментарии к примерам. Сохраняйте пометки beta, устаревания и незавершённости. Перевод заглушки содержит только имеющийся текст; недостающие руководства не дописываются.

Используйте термины из [глоссария](GLOSSARY.md). После машинного первого прохода сверяйте перевод с оригиналом: технические слова, отрицания, версии, область действия настроек и побочные эффекты требуют отдельного внимания.

## Сохраните технический синтаксис

Не переводите команды, флаги, пути, имена файлов, ключи конфигурации, API и идентификаторы. Сохраняйте служебные заголовки спецификаций и шаблонов, включая `Requirement:`, `Scenario:`, `ADDED Requirements`, а также `SHALL`, `MUST`, `WHEN`, `THEN`, `GIVEN`, `AND`, `FROM`, `TO`.

Запросы пользователя к ИИ и поясняющие комментарии переводятся. Реальный вывод программы остаётся в исходном виде и получает русское пояснение. [Пояснения к примерам](EXAMPLE_NOTES.md) связаны с конкретными блоками страниц. Дополнительный русский текст не выдаётся за реальный вывод CLI.

## Проверьте переходы

Ссылки на переведённые страницы направляйте в русский комплект. Сохраняйте исходные якоря явными HTML-якорями перед переведёнными заголовками. Используйте относительные URL с `/` и точный регистр имён файлов.

Переход на английский оригинал или внешний англоязычный материал обозначайте в подписи. Для изображений с английским интерфейсом добавляйте русское описание всех значимых надписей. Крупная кнопка главного README хранится локально в `assets/`.

## Зафиксируйте сверку

Каждая запись содержит `source`, `translation`, `sourceCommit`, `sourceBlob`, `status`. Статусы:

| Значение | Смысл |
|---|---|
| `pending` | Перевод ещё не выполнен |
| `draft` | Перевод требует сверки |
| `reviewed` | Имеющийся полный оригинал переведён и сверен |
| `source-incomplete` | Весь имеющийся текст переведён, но оригинал не завершён |

Для `source-incomplete` добавьте на страницу видимую пометку:

> Оригинал этой страницы ещё не завершён. Ниже переведён весь имеющийся текст; недостающие разделы не дописывались.

Статус в реестре вместе с этой пометкой допускает приёмку перевода доступного текста. Проверка сохраняет `source-incomplete` как предупреждение с `severity: "warning"`. Отсутствующая пометка (`missing-source-notice`) или незавершённость обнаруженного оригинала без нужного статуса (`unmarked-source-incomplete`) блокируют приёмку. Отставание, неверные версии и ошибки ссылок остаются блокирующими при любом статусе.

`stale` вычисляется проверкой, если оригинал отличается от сохранённой версии, в том числе при незакоммиченной правке. CRLF и блок кнопки русского входа исключаются из этого сравнения.

Меняйте проверенные SHA после сверки текста, примеров и ссылок. Повышение версии в метаданных само по себе не обновляет перевод. Порядок работы и команды находятся в [инструкции обновления](UPSTREAM_SYNC.md).
