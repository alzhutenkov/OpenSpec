# Пояснения к выводу, примерам и схемам

Здесь переведён смысл английских подписей и сообщений из документации. Исходные блоки на связанных страницах сохраняются для сопоставления с реальным CLI. Команды запуска и файлы конфигурации копируйте с этих страниц.

<a id="example-001"></a>
## Пример 1: OpenSpec

[Вернуться к странице](project/README_OLD.md).

```text
┌────────────────────┐
│ Черновик изменения │
│ Предложение │
└────────┬───────────┘
│ делится намерением с вашим ИИ
         ▼
┌────────────────────┐
│ Проверка и согласование │
│ (редактировать спецификации /tasks) │◀──── контур обратной связи ──────┐
└────────┬───────────┘                          │
│ утвердил план │
         ▼                                      │
┌────────────────────┐                          │
│ Реализация задач │──────────────────────────┘
│ (ИИ записывает код) │
└────────┬───────────┘
│ отправляет изменения
         ▼
┌────────────────────┐
Архив │ и обновление │
Спецификации │ (источник) │
└────────────────────┘

1. Подготовьте предложение по изменению, отражающее нужные обновления спецификации.
2. Рассмотрите предложение с ИИ-помощником, пока все не согласятся.
3. Реализуйте задачи, соответствующие согласованным спецификациям.
4. Заархивируйте изменения, чтобы объединить утвержденные обновления обратно в основные спецификации (источник истины).
```
