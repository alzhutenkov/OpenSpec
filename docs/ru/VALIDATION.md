# Результаты проверки русского комплекта

Проверка выполнена 27 октября 2026 года для оригиналов из коммита `6d04a1b58dedc95729d34e4f223d9d483aae210a`.

## Охват

В [реестре](translation-manifest.json) 83 документа. Переведён весь имеющийся текст каждого источника. Английские документы остаются на прежних путях; основной README дополнен только блоком входа в русский раздел.

Из них 18 оригиналов ещё не завершены: у них состояние `source-incomplete`. На соответствующих страницах есть предупреждение, а в [русском индексе](README.md) они выделены отдельно. Недостающий текст оригинала не дописывался.

Для каждой страницы сохранены путь источника, проверенный коммит и Git blob. В начале перевода есть переход к оригиналу и проверенной версии. Поле `translationMethod` указывает ручной или машинный перевод с последующей проверкой.

## Что проверено

- Полнота реестра относительно согласованного набора исходных файлов.
- Соответствие версий оригиналов; нет необработанных изменений и исчезнувших источников.
- Существование локальных ссылок, изображений и якорей, включая переходы между русскими страницами.
- Сохранение исходной навигации: готовые переводы открываются внутри русского комплекта.
- Наличие исходных технических фрагментов в обратных кавычках и маркеров `SHALL`/`MUST`; последовательность блоков кода.
- Точное совпадение 36 блоков реального вывода CLI с исходными примерами.

Для 61 примера и блока вывода подготовлены [русские пояснения](EXAMPLE_NOTES.md), доступные из 63 мест документации. Реальные английские сообщения сохранены для сопоставления с терминалом.

Для английских заголовков сохранены явные якоря. Ссылки на конкретные разделы продолжают работать после перевода заголовков. У скриншота панели есть русское пояснение подписей и показателей.

## Проверка инструмента сопровождения

```bash
node --test scripts/check-russian-docs.test.mjs
```

Десять тестов проверяют изменения, новые и исчезнувшие источники, переименование, пропущенные и черновые переводы, некорректный реестр, SHA, ссылки, якоря и точный регистр путей. Отдельно проверены CRLF, каталог с пробелами, режим отчёта без записи файлов и русские переходы.

Тест слияния создаёт отдельный временный Git-репозиторий. В нём обновляются оригинал и README, добавляется документ, переименовывается другой. После разрешения конфликта README остаётся русский вход; обе исходные ветки входят в историю результата. Незатронутая страница не объявляется устаревшей.

## Проверка всего комплекта

```bash
node scripts/check-russian-docs.mjs
node scripts/check-russian-docs.mjs --json
node scripts/check-russian-docs.mjs --strict
```

Отчёт содержит только 18 замечаний `source-incomplete`. Пропущенных источников, переводов, черновиков, отставших версий и ошибок локальной навигации нет.

`--strict` возвращает код 1 из-за этих незавершённых оригиналов. Это сохраняет критерий SDD: перевод пустых заголовков не превращает страницу в готовое руководство. Полную готовность можно подтвердить после появления исходного текста и обновления перевода.

## Платформы и границы проверки

Локальные тесты выполнены на macOS. [Процесс CI](../../.github/workflows/russian-docs.yml) подготовлен для Windows, macOS и Linux с полной историей Git. Фактические запуски CI на Windows и Linux ещё не подтверждены.

Команды установки и примеры сверялись с оригиналами; все установщики, редакторы и внешние сервисы заново не запускались. Сетевые ссылки и доступность сторонних сайтов не входят в локальную проверку. Прежние руководства сохраняют пометки устаревания, включая известное расхождение README сайта с текущим источником сборки.

Основной машинный проход выполнен через Google Translate после разрешения пользователя; ключевые руководства и справочники отредактированы вручную. Первоначальный локальный проход не использован как окончательный текст. Техническая проверка не заменяет последующую редактуру формулировок при обновлении документации.

Порядок дальнейшей сверки: [обновление из исходного репозитория](UPSTREAM_SYNC.md).
