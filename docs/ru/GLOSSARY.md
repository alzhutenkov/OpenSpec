# Русский глоссарий

Имена продукта, инструментов, файлов и команд сохраняют исходное написание. Справочник терминов самого продукта: [глоссарий OpenSpec](docs-lab/reference/glossary.md).

| Термин | Русское обозначение |
|---|---|
| spec, specification | спецификация |
| spec-driven development, SDD | разработка по спецификациям |
| change | изменение: каталог с планом, спецификациями и задачами |
| proposal | предложение изменения |
| design | техническое решение |
| task | задача |
| artifact | артефакт: документ рабочего процесса |
| delta spec | изменения спецификации |
| main specs | основные спецификации |
| capability | возможность системы |
| requirement | требование |
| scenario | сценарий |
| workflow | рабочий процесс |
| skill | навык агента |
| command | команда |
| delivery | форма установки: навыки, команды или обе формы |
| profile | профиль, набор устанавливаемых процессов |
| schema | схема рабочего процесса |
| template | шаблон |
| store | хранилище: отдельный репозиторий планирования |
| workset | рабочий набор: хранилище и связанные репозитории |
| root | корень проекта или выбранного хранилища |
| context | контекст проекта |
| rules | правила для артефактов |
| operations | указания для операций |
| apply | выполнение задач изменения |
| sync | синхронизация изменений спецификаций |
| archive | архивирование завершённого изменения |
| upstream | исходный репозиторий проекта |
| fork | форк, собственная копия репозитория |
| merge | слияние веток Git |
| drift, stale | расхождение с проверенной версией, отставание |
| legacy | прежний, возможно устаревший набор |
| beta | предварительная возможность; ограничения сохраняются |
| breaking change | несовместимое изменение |
| shell completion | автодополнение команд оболочки |

## Служебные слова спецификаций

Эти слова остаются по-английски в машинном синтаксисе:

| Слово | Значение |
|---|---|
| `SHALL`, `MUST` | обязательное требование: должен |
| `SHOULD` | рекомендация: следует |
| `MAY` | разрешённая возможность: может |
| `GIVEN` | исходное условие: дано |
| `WHEN` | событие: когда |
| `THEN` | ожидаемый результат: тогда |
| `AND` | дополнительное условие или результат: и |
| `ADDED` | добавленные требования |
| `MODIFIED` | изменённые требования |
| `REMOVED` | удалённые требования |
| `RENAMED` | переименованные требования |
| `FROM`, `TO` | прежнее и новое имя |
| `Requirement:` | требование |
| `Scenario:` | сценарий |
