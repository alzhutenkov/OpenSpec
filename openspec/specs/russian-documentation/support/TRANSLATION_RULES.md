# Правила перевода и повторного создания комплекта

Источник требований: [актуальная SDD](../spec.md). Эти правила, [глоссарий](GLOSSARY.md) и [реестр](translation-manifest.json) хранятся вне `docs/ru/` и сохраняются при повторном создании перевода.

## Определите весь набор источников

Используйте набор из SDD: Markdown в `docs-lab/` и прежнем `docs/`, согласованные корневые документы и README подсистем. Сам `docs/ru/` источником не является. Машинные инструкции, шаблоны генерации, код, тесты и `openspec/` исключены; причины записаны в реестре.

Сопоставьте набор с текущими файлами проекта. Обработайте все источники, включая новые страницы. Отсутствие прежнего русского каталога не сокращает область перевода.

## Сохраните исходное дерево

Для каждого пути `<source>` используйте перевод `docs/ru/<source>`:

| Оригинал | Перевод |
|---|---|
| `README.md` | `docs/ru/README.md` |
| `CONTRIBUTING.md` | `docs/ru/CONTRIBUTING.md` |
| `CHANGELOG.md` | `docs/ru/CHANGELOG.md` |
| `docs/README.md` | `docs/ru/docs/README.md` |
| `docs-lab/start/setup.md` | `docs/ru/docs-lab/start/setup.md` |

Имена, регистр и вложенность сохраняются. Промежуточный `project/` для корневых файлов не используется. Перезаписывайте файлы по точному соответствию в реестре. Исчезнувшие и переименованные источники разбирайте по одной записи; сохраняйте прежний перевод до явного решения по нему.

## Сохраните структуру каждой страницы

Переведите весь доступный текст. Сохраните порядок и уровни заголовков, списки, строки и столбцы таблиц, изображения, раскрывающиеся блоки и примеры на соответствующих местах. Сохраняйте ограничения, предупреждения, beta и пометки устаревания.

`docs/ru/README.md` содержит полный перевод корневого README. При сверке исключите из английского оригинала только отмеченный блок русского входа. Служебное дополнение к русскому README: отдельная ссылка на SDD в конце страницы. Сведения о переводе можно записать в невидимом HTML-комментарии. Служебный индекс, инструкции обновления и отчёт не заменяют содержимое оригинала.

Прежний `docs/` переводится с предупреждением об устаревании. Незавершённые оригиналы получают статус `source-incomplete` и видимую пометку:

> Оригинал этой страницы ещё не завершён. Ниже переведён весь имеющийся текст; недостающие разделы не дописывались.

Недостающий текст не дописывается от имени upstream. Принимается перевод всего доступного текста с явным указанием ограничения.

## Сохраните технические обозначения

Используйте термины из [глоссария](GLOSSARY.md). Команды, флаги, пути, имена файлов, ключи конфигурации, API и идентификаторы сохраняют исходное написание. Это относится и к именам в деревьях каталогов и примерах диалогов.

В примерах спецификаций и шаблонов сохраняйте служебные заголовки `Requirement:`, `Scenario:`, `ADDED Requirements`, а также `SHALL`, `MUST`, `WHEN`, `THEN`, `GIVEN`, `AND`, `FROM`, `TO`. Переводите поясняющий текст, комментарии и запросы пользователя к ИИ.

Реальные сообщения CLI сохраняются для сопоставления с терминалом и получают русское объяснение. Дополнительные пояснения к схемам и сообщениям находятся в [EXAMPLE_NOTES.md](EXAMPLE_NOTES.md). Они не выдаются за исполняемые команды или фактический вывод.

## Восстановите переходы

Ссылки на переведённые документы направляются в русский комплект по реестру. После перевода заголовка сохраните исходный якорь. Относительные URL используют `/` и точный регистр, чтобы работать в GitHub, Windows, macOS и Linux.

Переходы на английские оригиналы и англоязычные внешние материалы обозначаются в подписи. Изображения с английским интерфейсом получают русское пояснение. Кнопка английского README использует отдельный ресурс `assets/russian-docs-button.svg` вне пересоздаваемого комплекта.

## Зафиксируйте сверенную версию

Запись реестра содержит `source`, `translation`, `sourceCommit`, `sourceBlob`, `status`:

| Статус | Значение |
|---|---|
| `pending` | Перевод ещё не выполнен |
| `draft` | Перевод требует сверки |
| `reviewed` | Полный имеющийся оригинал переведён и сверен |
| `source-incomplete` | Весь доступный текст переведён, но оригинал не завершён |

Версия меняется после сверки текста, примеров и ссылок. Одно обновление SHA не подтверждает актуальность перевода. CRLF и блок русского входа исключаются из сравнения содержимого оригинала. При повторном создании комплекта восстановите записи по текущим источникам и укажите действительно сверенные версии.

## Проверьте результат как агент

Сопоставьте каждый источник с переводом. Проверьте полноту, дерево файлов, структуру страниц, ссылки, изображения, команды и примеры. Исправьте ошибки до завершения работы. Сведения об оставшихся ограничениях оригиналов сохраните в [отчёте](VALIDATION.md).

Актуальная основная SDD имеет приоритет над прежним архивным решением, в котором корневые переводы располагались в `project/`. Порядок получения исходных изменений: [UPSTREAM_SYNC.md](UPSTREAM_SYNC.md).
