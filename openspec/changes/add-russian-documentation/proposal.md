# Русская документация без расхождения с исходным репозиторием

## Why

Читателю без знания английского нужен полный русский комплект документации OpenSpec. Перевод должен развиваться рядом с оригиналами, чтобы сохранялась история Git и обновления Fission-AI/OpenSpec можно было принимать обычным слиянием.

## What Changes

- **Русский раздел.** Сейчас отдельного комплекта нет. Появится `docs/ru/` с русской главной страницей, переводами актуальной и прежней документации и материалами для участников проекта.
- **Вход из README.** Сейчас основной README ведёт в английскую документацию. В начале появится крупная локальная кнопка «Документация на русском» с обычной текстовой ссылкой.
- **Сопровождение перевода.** Сейчас соответствие переводов оригиналам не учитывается. Для каждой страницы появятся путь оригинала, проверенная версия и состояние перевода; изменения оригиналов будут видны в отчёте.
- **История и обновления.** Английские документы останутся на прежних путях. Перевод добавляется отдельными коммитами; основной README меняется только в блоке русского входа.

Полнота означает перевод всего согласованного набора документации, а не только README и быстрого старта. Английские технические обозначения сохраняются там, где они нужны для выполнения команд и разбора файлов.

## Capabilities

### New Capabilities

- `russian-documentation`: русский комплект документации, переходы между языками, полнота перевода и видимость отставания от оригинала.

### Modified Capabilities

Нет. Контракты CLI и генерации инструкций не меняются.

## Impact

- Добавляются `docs/ru/` и небольшой блок в корневом `README.md`.
- Планируются реестр переводов, проверка полноты, ссылок и актуальности, инструкция обновления из upstream.
- Источники: `docs-lab/` (актуальные материалы, включая ещё не законченные страницы), `docs/` (прежняя документация), корневые руководства и README подсистем. Точный охват и исключения: `design.md`.
- Сайт сейчас собирается из `docs-lab/`. Публикация русской версии сайта и перевод сообщений CLI в эту работу не входят.
- После подготовки SDD реализуются полный перевод согласованного набора, проверка версий и русская навигация. Незавершённые оригиналы выделяются отдельно; их заголовки не выдаются за готовые руководства.
