# Русская документация с обновлениями из upstream

## Why

Читателю без знания английского нужен отдельный русский комплект документации OpenSpec. Перевод должен сопровождаться независимо от оригиналов, чтобы новые версии Fission-AI/OpenSpec можно было принимать обычным слиянием Git с сохранением истории.

## What Changes

- **Документация:** вместо смешивания языков в исходных страницах появляется отдельный комплект в `docs/ru/`. Английские документы остаются на прежних путях.
- **Навигация:** в начале основного README появляется крупная кнопка перехода в русский раздел и текстовая ссылка на ту же страницу.
- **Обновления:** каждой переводимой странице сопоставляются оригинал и проверенная версия. После слияния upstream видны новые, изменённые и исчезнувшие источники.
- **Приёмка:** сопровождающий запускает проверку вручную. Незавершённый оригинал допускается, если весь доступный текст переведён и сверен, а незавершённость отмечена на русской странице и в реестре.
- **Конфликты:** переводы изолированы от английских страниц. Единственное изменение основного README ограничено отмеченным блоком; для него описывается разрешение возможного конфликта.

Полное отсутствие конфликтов при любых будущих изменениях upstream не гарантируется. Контракт исключает конфликты, вызванные заменой английского текста переводом, и ограничивает общие правки README отдельным блоком.

## Capabilities

### New Capabilities

- `russian-documentation`: отдельный русский комплект, точка входа, соответствие оригиналам и сопровождение обновлений.

### Modified Capabilities

Нет. Поведение CLI и форматы его данных сохраняются.

## Impact

- Новый каталог `docs/ru/`; небольшой блок в корневом `README.md`.
- Реестр переводов, локальная ручная проверка актуальности и ссылок, инструкция обновления из upstream. Отдельный CI для русской документации не требуется.
- Источники: актуальный `docs-lab/`, прежний `docs/`, корневые руководства и README подсистем. Границы определены в `design.md`.
- Локальные навыки OpenSpec подключены через `.agents/skills/`; `openspec/config.yaml` уже существовал и сохраняется.
- Изменение включает полный перевод доступного текста, русскую точку входа, кнопку и ручную проверку. Отсутствующий текст исходных страниц не дописывается.
